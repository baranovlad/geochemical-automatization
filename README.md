# Кластеризация геохимических данных

![](https://habrastorage.org/webt/6b/8d/5e/6b8d5e384e564848677548ed72a0f140.jpg)

Автоматизация анализа геохимических проб методом k-средних. Скрипт обрабатывает исходные данные, фильтрует аномалии, проводит кластеризацию и формирует структурированный Excel-отчёт с интерактивной картой распределения проб — готовый к интерпретации специалистом.

---

## Постановка задачи

Ручной анализ геохимических данных занимает много времени и плохо воспроизводится. Проект автоматизирует пайплайн корреляционного анализа и выдаёт данные, пригодные для выявления геохимических ассоциаций, в том числе потенциально золоторудных.

---

## Как работает

1. **Загрузка** исходных данных из Excel (координаты + содержание элементов)
2. **Логарифмирование** — геохимические данные имеют логнормальное распределение
3. **Расчёт статистик** — среднее, стд, мода, асимметрия, коэффициент вариации, пороговые уровни (1σ, 2σ, 3σ)
4. **Фильтрация выбросов** — значения выше порога 2σ заменяются на пороговое значение
5. **Нормализация** через `StandardScaler` — устраняет влияние масштаба между элементами
6. **Кластеризация** методом k-средних (11 кластеров, 300 инициализаций)
7. **Экспорт** результатов в Excel и генерация интерактивной карты

---

## Входные данные

Excel-файл (`bd_float.xlsx`), где каждая строка — точка пробоотбора:

| Столбец | Описание |
|---------|----------|
| `x msk`, `y msk` | Координаты (система МСК) |
| `Ag`, `As`, `Au`, ... | Содержание химических элементов |

---

## Результаты

| Файл | Содержимое |
|------|------------|
| `data.xlsx` → `general_stats` | Генеральные характеристики по каждому элементу (среднее, стд, перцентили, пороги аномалий) |
| `data.xlsx` → `cluster_means` | Средние значения элементов по кластерам |
| `map.html` | Интерактивная карта точек пробоотбора с цветовой разметкой кластеров |
| `heatmap_cluster_N.png` | Корреляционная тепловая карта для кластера N |

## Запуск

```bash
pip install pandas numpy scikit-learn plotly seaborn openpyxl
python main.py
```

Основные параметры в `main.py`:

```python
path = 'bd_float.xlsx'   # путь к входному файлу
count_clusters = 11       # количество кластеров
count_init = 300          # количество инициализаций KMeans
required_level = 'second' # порог аномалий (first / second / third = 1σ / 2σ / 3σ)
```

## Оценка качества

Результаты кластеризации сравнивались с эталонной разметкой из **Statistica 10** с помощью **индекса Rand**:

```
Rand Index = 0.83
```

Значение 1.0 соответствует идеальному совпадению. Результат 0.83 подтверждает высокое сходство автоматической кластеризации с экспертной.
